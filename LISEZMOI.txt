FireStation Manager - Integration (Qt Widgets, Qt 6, qmake)

Ouvrir dans Qt Creator : Fichier > Ouvrir un fichier ou projet > FireStationManager.pro
Choisir un kit Qt 6 (modules necessaires : Widgets, Sql, Charts, PrintSupport),
puis Compiler et Executer (Ctrl+R).

DEMARRAGE
1. Fenetre de connexion (nom d'utilisateur + mot de passe). Pour le moment, "Se connecter"
   ouvre l'application meme si les champs sont vides (voir LoginDialog::verifierIdentifiants()).
2. Menu principal : une tuile par module (menupage.cpp). Pour le moment, tous les modules
   sont accessibles ; MenuPage::setModulesAutorises() permettra plus tard de n'afficher que
   les modules lies au poste de l'employe connecte.
3. Le module choisi s'ouvre avec la sidebar commune ; le bouton "Menu" ramene au menu principal.

MODULES INTEGRES (sidebar commune, barre du haut commune)
- Interventions .............. interventionspage.cpp/.h + rightpanel   (branche intervention)
- Equipe ..................... employespage.cpp/.h/.ui + qrgen.h        (branche gestion-des-employes,
                               module d'origine sans modification de sa logique)
- Vehicules .................. vehiculespage.cpp/.h/.ui                (branche gestion-vehicule)
- Carte (Zones de couverture)  zonespage.cpp/.h/.ui, zone, cartezoneswidget
                               (cree selon le cahier : la branche gestion-zones ne contenait
                               qu'une copie du module Interventions)
- Equipements ................ equipementspage.cpp/.h/.ui, equipement, equipementmodel, exports
                               (branche gestion-d'equipements)
- Campagne de Sensibilisation  campagnespage.cpp/.h/.ui, campagne, barchartwidget
                               (branche gestion-campagnes-sensibilisation)

MODULE ZONES (Chef de centre)
- CRUD des zones (ID, nom, region/quartier, superficie, population, niveau de risque,
  temps d'intervention moyen, latitude/longitude) avec controles de saisie.
- Tri (niveau de risque, temps d'intervention, nom), recherche (nom, region), export PDF / Excel.
- Statistiques : interventions par zone ou par niveau de risque (12 derniers mois).
- Metier innovant 1 : carte de Tunis des zones a risque, couleur calculee a partir de
  l'historique des interventions (pour 10 000 habitants).
- Metier innovant 2 : alerte de zone sous-couverte quand le temps d'intervention moyen
  depasse le seuil choisi.

PRINCIPE D'INTEGRATION
- mainwindow.cpp : sidebar + barre du haut + QStackedWidget (ordre des pages = enum Page).
- Chaque module garde son propre code et son .ui ; sa propre sidebar/en-tete est simplement
  masquee dans son constructeur (setWindowFlags(Qt::Widget) + hide()).
- Base de donnees SQLite commune "firestation.db" (dossier de donnees de l'application),
  ouverte une seule fois dans main.cpp (connection.cpp) : tables EQUIPEMENT, CAMPAGNE,
  ZONE_COUVERTURE, EMPLOYE, INTERVENTION. Les colonnes LATITUDE/LONGITUDE des zones sont
  ajoutees automatiquement si la base existait deja.
- Images et icones : resources.qrc (icons/nav/ = icones blanches de la sidebar,
  images/campagnes/ et images/employes/ = images des modules ; images/sidebar_bg_clean.png =
  fond de la sidebar sans texte).
- style.qss : style global ; les regles des tableaux/listes deroulantes sont limitees
  a la page Interventions pour ne pas modifier les autres modules.

AJOUTER UN MODULE
1. Copier ses fichiers, renommer sa classe MainWindow en <Module>Page (et son .ui).
2. Dans son constructeur : setWindowFlags(Qt::Widget) puis masquer sa sidebar/en-tete.
3. L'ajouter dans FireStationManager.pro, puis dans mainwindow.cpp a la place du placeholder.
