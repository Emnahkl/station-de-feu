# Projets de l’intégration

Ce dossier contient une copie propre des deux projets Qt, chacun dans son propre sous-dossier :

- `vehicule/` : contenu de la branche `gestion-vehicule` (commit `cd17435`). Ouvrir `vehicule/gestionvehicule.pro` dans Qt Creator.
- `intervention/` : contenu de la branche `intervention` (commit `a5ee42d`). Ouvrir `intervention/GestionInterventions.pro` dans Qt Creator.

Les deux applications restent séparées afin de conserver leurs fichiers d’entrée et leurs ressources propres. Les dossiers de compilation et les réglages locaux de Qt Creator ne sont pas inclus.
